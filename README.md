# Neon Comet 3.0

A 2D pixel-art space shooter that runs in the browser as a PWA. It is a set of static files with no build step and no npm, hosted on Cloudflare Pages. You can play it on a phone in landscape (touch), on a PC (mouse/keyboard) or with a gamepad (including a PS5 DualSense over Bluetooth). It works offline once it has loaded.

## Structure

```
index.html              entry; the script order is fixed (SPEC.md §9)
sw.js                   service worker: precaches everything, network-first for pages/js/css/json
_headers                Cloudflare Pages headers (no-cache for code, immutable fonts)
manifest.webmanifest    PWA manifest (orientation: landscape)
css/style.css           all UI styles (sizes are calc(var(--u) * N), with --u = integer UI scale)
fonts/                  Silkscreen + Micro 5 (OFL, see fonts/LICENSES.md)
icons/                  app icons (tools/release/make_icons.py) + og.jpg
assets/manifest.json    sprite manifest (id -> file, size, frames, fps, anchor)
assets/sprites/         every sprite PNG at 1x (generated by tools/art)
js/i18n.js              NC.t / NC.I18N (RO without diacritics + EN)
js/data.js              all game numbers (ships, weapons, enemies, bosses, pacing, economy)
js/save.js              v4 save + migration from v3/v2 (localStorage neonComet.v4)
js/systems.js           NC.sys: shop, upgrades, gear/merge/sell, chests, missions, achievements, revive
js/audio.js             procedural WebAudio chiptune music + SFX
js/engine/*.js          renderer, input (touch/kb/mouse/gamepad), enemies, bosses, weapons, fx, game loop
js/ui/*.js              DOM UI: loading screen, menus, hangar, HUD, overlays, settings
tools/art/              sprite generators (python3 tools/art/build_all.py, then validate.py)
tools/balance/          economy model + simulation (node tools/balance/sim.js)
tools/release/          gen_sw.py (precache list), make_icons.py
dev/                    test harnesses (not loaded by the game; safe to deploy or exclude)
```

## Run locally

```
cd game && python3 -m http.server 8000     # open http://localhost:8000/
```

Debug hooks are in the browser console: `NC.debug.state()`, `setScore(49990)`, `killBoss()`, `godMode(true)`, `setSector(2)`, `simulate(300)`.

## Tests

You need Python 3 with Playwright and Chromium installed. Each script starts its own `http.server` on a free port and stops it when it finishes.

| command | what it checks |
|---|---|
| `python3 dev/integration/e2e.py` | Full end-to-end run. It covers desktop 1280x720, phone 844x390 touch, portrait (rotate overlay), a standard gamepad and a raw DualSense layout, plus hangar, run, bosses, revive, share, missions, settings, offline reload and v3 save migration. It also checks for console errors, failed requests, raw i18n keys and overflow. The report goes to `dev/integration/e2e_report.txt` and screenshots to `dev/integration/shots/`. |
| `python3 dev/integration/bot5min.py 300` | 5-minute real-time bot run with no errors |
| `python3 dev/integration/pacing2.py 6` | Pacing with the headless sim: times to the mini-boss, first boss and events |
| `node dev/integration/i18n_check.js` | Static check that every i18n key exists in RO and EN, with no diacritics |
| `node dev/systems/test.js` | Systems / save unit tests |
| `python3 tools/art/validate.py` | Sprite manifest vs SPEC |
| `python3 dev/integration/review_pack.py` | Owner review screenshots + `dev/integration/overview.png` |

## Release

1. Bump `VERSION` in `sw.js` (for example `neon-comet-v5` -> `neon-comet-v6`). Players pick up the update on the next load.
2. If files were added or removed (sprites, js), run `python3 tools/release/gen_sw.py` to regenerate the precache list.
3. Run `python3 dev/integration/e2e.py` and make sure the report says all checks passed.
4. Commit and push to GitHub. Cloudflare Pages deploys the folder as is, so there is no build command.

Saves live in localStorage and are never touched by updates.
